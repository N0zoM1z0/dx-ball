## Why this question was new

The earlier [surface-member control](CLOSED_STORAGE_DIAGNOSTICS.md#rotation-surface-member-calls)
used the old aggregate board declaration context. Its actual C++ object retains
all four original bank-first groups in offset and width; width was completely
exact, while offset had only a final comparison transpose. The later independent
seven-global model changed those four groups in the C owner to slot-first,
adding one byte each. No equivalent C++ control in this current context was
found in the bounded retained rotation experiments.

This establishes a concrete producer question independent of the successful
bonus owner. One current-context compile compares all six complete functions,
including the three prior exacts. It does not retry inline helpers, arithmetic
spellings, types, source order, flags or selective headers.
